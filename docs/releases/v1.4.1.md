# Seoul Bike v1.4.1

## Home Assistant 2026.11 CPU 사용량 수정

Home Assistant 2026.11부터 `DeviceEntry.config_entries`는 폐기 예정(deprecated) 속성입니다. 이 속성을 읽을 때마다 Home Assistant는 호출한 통합을 찾으려고 콜스택 전체와 불러온 모듈 전체를 훑습니다. 1.4.0의 즐겨찾기 정리(`sync_favorite_registry`)는 데이터를 갱신할 때마다 기기 레지스트리 **전체**를 돌면서 이 속성을 읽었습니다. 그래서 기기가 많은 설치(실측 818개)에서는 이벤트 루프 CPU의 약 17%를 이 통합 하나가 썼습니다.

- 이 항목(계정)의 기기만 레지스트리 인덱스(`device_registry.async_entries_for_config_entry`)로 가져옵니다. 전체 기기를 훑지 않습니다.
- 기기 소유 항목은 2026.11의 `config_entry_id`로 판단합니다. 이전 Core(`config_entry_id`가 없는 경우)에서는 지금처럼 `config_entries`를 씁니다. 복원된 composite 기기도 지금처럼 `config_entries`를 씁니다.
- 즐겨찾기 정리 규칙은 그대로입니다. 다른 계정이나 다른 통합과 공유하는 기기, 엔티티가 남아 있는 기기는 지우지 않습니다.

엔티티 ID·unique_id, 폴링 주기, 로그인/재인증 처리는 바꾸지 않았습니다.
